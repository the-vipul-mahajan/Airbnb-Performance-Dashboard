# 🏡 Airbnb Data Analysis Dashboard | Power BI

## 📌 Project Overview

This project is an interactive Power BI dashboard built using the Airbnb dataset. The goal was to explore listing, host, pricing, and review data to understand customer behavior and identify useful business insights. Throughout this project, I cleaned the data, created DAX measures, and designed interactive visuals to present the findings in a simple and meaningful way.

---

## 🎯 Business Problem

Airbnb has thousands of listings, hosts, and customer reviews. Looking at raw data makes it difficult to answer important questions such as:

- Which cities have the highest number of listings?
- How many hosts are verified?
- How are listing prices distributed?
- How active are reviewers?
- Which listings are available throughout the year?

This dashboard helps answer these questions through interactive visualizations.

---

## 🎯 Dashboard Goal

The main goal of this project was to build a dashboard that allows users to:

- Analyze Airbnb listings across different cities
- Compare host verification and profile information
- Understand customer review patterns
- Explore pricing and availability trends
- Make data-driven decisions using interactive reports

---

## 🛠️ Tech Stack

- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel / CSV

---

## 📂 Data Source

- Airbnb Open Dataset (CSV Files)

The dataset contains information about:
- Listings
- Hosts
- Reviews
- Prices
- Availability
- Locations

---

## 📊 Dashboard Highlights

### 📍 Listings Analysis
- Total number of listings
- City-wise listing distribution
- Interactive filters for easy analysis

### 👤 Host Analysis
- Total hosts
- Verified vs. non-verified hosts
- Hosts with and without profile pictures
- Host verification percentages

### ⭐ Reviews Analysis
- Review frequency distribution
- Cumulative review percentage
- Reviewer activity analysis
- Identification of highly active reviewers

### 💰 Pricing Analysis
- Average listing price
- Price comparison across cities
- Price distribution

### 📅 Availability Analysis
- Listing availability throughout the year
- Availability trends across locations

---

## 📈 Key Insights

- Around **86.5%** of reviewers wrote only **one review**.
- More than **96%** of reviewers wrote **two or fewer reviews**.
- One reviewer wrote **283 reviews**, making them a clear outlier.
- Most hosts are verified and have profile pictures.
- Listing prices and availability vary significantly between cities.
- A few cities contribute the majority of Airbnb listings.
